Welcome to My Network

Connect your GitHub repository to load your contacts. You'll need a Personal Access Token and a repo containing data.json.

Settings

How to set this up
  1. Create a GitHub account at github.com
  2. Create a new public repository named my-network (or any name) and upload index.html and data.json
  3. Go to Settings > Developer Settings > Personal Access Tokens > Tokens (classic)
  4. Create a token with repo scope
  5. Paste your token, username, and repo name above, then save
